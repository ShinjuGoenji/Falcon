## Module Initialization

**Quick start**:
```bash
cd /home/daniel_kuo/Falcon
bash init_module.sh my_new_module
```

**What it does**:
- Creates directory structure: `00_TESTBED/`, `01_RTL/`, `02_SYN/`, `03_GATE/`, `04_MEM/`, `golden/`
- Copies and customizes Makefiles, filelist.f, syn.tcl
- Generates DESIGN_NOTES.md template
- Creates softlinks in 01_RTL and 03_GATE
- Ready for RTL simulation immediately

**Script location**: `./init_module.sh` (executable, tracked in git)

## Testing & Debugging

### Extract Test Vectors from C Code
1. Add `fprintf()` at module boundaries in `software/`
2. Capture input and output to text files
3. Place in `hardware/<module>/00_TESTBED/`
4. Update PATTERN.sv to read from these files

### Common Simulation Issues

| Issue | Solution |
|-------|----------|
| "No such file or directory" in vcs | Check filelist.f softlinks and `00_TESTBED/` files |
| Waveform not generated | Check TESTBED.sv `fsdb` dump statement |
| Synthesis timing fails | Redesign for parallelism/pipelining, don't relax period |
| Library not found in DC | Check `.synopsys_dc.setup` paths |
